# RadioCoravox-iOS

Proyecto iOS independiente para continuar el desarrollo de Radio Coravox. Abre [RadioCoravox/RadioCoravox.xcodeproj](RadioCoravox/RadioCoravox.xcodeproj) en macOS con Xcode. Desde Windows puede compilarse el simulador con GitHub Actions; la firma y la instalación en iPhone se hacen mediante TestFlight.

La rama de trabajo en GitHub es `ios/wkwebview-native-playback`. La compilación iOS requiere macOS/Xcode; no se instala Xcode ni se firma una app localmente en Windows.

Consulta [la guía de compilación y pruebas](RadioCoravox/README.md).
