# RadioCoravox-iOS

Proyecto iOS independiente para continuar el desarrollo de Radio Coravox. Abre [RadioCoravox/RadioCoravox.xcodeproj](RadioCoravox/RadioCoravox.xcodeproj) en macOS con Xcode.

La rama de trabajo en GitHub es `ios/wkwebview-native-playback`. Esta carpeta local contiene el scaffold actual; la compilación en Windows no está disponible porque requiere Xcode/macOS.

Consulta [la guía de compilación y pruebas](RadioCoravox/README.md).
